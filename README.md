# Diagnóstico de Doenças Oculares com Deep Learning

Este projeto é uma implementação e aprimoramento do artigo 
[**DL-CNN-based approach with image processing techniques for diagnosis of retinal diseases**](https://link.springer.com/article/10.1007/s00530-021-00769-7), 
publicado por Akash Tayal, Jivansha Gupta, Arun Solanki, Khyati Bisht, Anand Nayyar e Mehedi Masud em 28 de março de 2021 pela Springer-Verlag GmbH Germany.

Esse projeto também pode ser acessado no Kaggle:

## 📝 Descrição do Projeto

Este trabalho propõe o desenvolvimento de uma ferramenta de diagnóstico automatizado baseada em redes neurais convolucionais (CNN) aplicadas a imagens de tomografia de coerência óptica (OCT) da retina.

O objetivo principal é classificar imagens em quatro categorias clínicas distintas:

- **Edema Macular Diabético (DME)**
- **Drusas**
- **Neovascularização Coroidal (CNV)**
- **Imagens Normais**
